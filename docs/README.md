# Docs

Planning and background docs for yashkadam.com. These record intent and history — the codebase
itself is described in `CLAUDE.md` at the repo root.

| File | What it holds |
|------|---------------|
| [PROJECT.md](PROJECT.md) | The living project brief: requirements (validated / active / out of scope), context, constraints, and the key-decisions log with rationale |
| [ROADMAP.md](ROADMAP.md) | Milestones and their phases at a glance |
| [MILESTONES.md](MILESTONES.md) | What each shipped milestone delivered, with stats |
| [RETROSPECTIVE.md](RETROSPECTIVE.md) | Lessons per milestone — what worked, what was inefficient |
| [milestones/](milestones) | Archived per-milestone roadmap and requirements |
| [research/](research) | Pre-build research from 2026-05-24: recommended stack, architecture patterns, feature landscape, and domain pitfalls |

`research/` is a point-in-time snapshot verified against Next.js 16.2.6 docs. It explains *why*
several of the constraints in `CLAUDE.md` exist, but treat its version claims as dated.
